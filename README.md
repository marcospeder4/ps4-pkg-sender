# 🎮 PS4 PKG Sender

<p align="center">
  <b>Una herramienta sencilla y eficiente para enviar archivos <code>.pkg</code> a tu consola PlayStation 4 mediante red local.</b>
  <br />
  <i>A simple and efficient tool to send <code>.pkg</code> files to your PlayStation 4 console over local network.</i>
</p>

---

## 🇪🇸 Español

### 🚀 Características
- 📦 **Envío rápido:** Transfiere e instala archivos `.pkg` directamente a tu PS4 por FTP / API de instalación.
- ⚡ **Fácil de usar:** Configuración rápida e interfaz ligera.
- 🌐 **Soporte de red local:** Sin necesidad de usar memorias USB externas.

### 📋 Requisitos Previos
- Una consola **PS4 liberada / jailbroken** (GoldHEN o HEN activado).
- Servidor FTP o instalador de PKGs activado en la PS4 (*GoldHEN FTP Server* y PS4PKGINSTALLER).
- La consola PS4 y la computadora/dispositivo deben estar en la **misma red local (LAN/Wi-Fi)**.

### 🛠️ Uso
1. Obtén la **dirección IP** de tu PS4 (*Ajustes > Red > Estado de la conexión*).
2. Abre la aplicación/herramienta `ps4-pkg-sender`.
3. Ingresa la IP de la PS4 y el puerto (por defecto FTP: `21` o Remote PKG: `12800`).
4. Selecciona el archivo `.pkg` que deseas enviar e inicia la transferencia.

## 🇬🇧 English

### 🚀 Features
- 📦 **Fast Transfer:** Send and install `.pkg` files directly to your PS4 via FTP / Installation API.
- ⚡ **Easy to use:** Quick setup and lightweight interface.
- 🌐 **Local Network Support:** No need to use external USB drives.

### 📋 Prerequisites
- A **jailbroken PS4 console** (with GoldHEN or HEN enabled).
- Active FTP Server or PKG installer payload on PS4 (e.g., *GoldHEN FTP Server* or *Remote PKG Installer*).
- Both the PS4 and your PC/device must be connected to the **same local network**.

### 🛠️ Usage
1. Find your PS4 **IP address** (*Settings > Network > View Connection Status*).
2. Launch `ps4-pkg-sender`.
3. Enter your PS4 IP address and port (default FTP: `21` or Remote PKG: `12800`).
4. Select the `.pkg` file you want to send and start the transfer.
